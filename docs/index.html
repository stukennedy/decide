decide.

Pick one of your options, with probabilities, in under a tenth of a second. Runs on your Mac.

curl -fsSL https://decide.run/install | sh

Apple Silicon Mac (M1 or later) · ~9 GB disk · ~10 GB free memory. No API key, and nothing leaves your machine.

$ decide ask "Customer: I was charged twice for order 1182." "Which team?" billing shipping tech
billing
  billing   1.000
  shipping  0.000
  tech      0.000

Use it anywhere you'd write an if statement about text

# describe options with id=description
$ decide ask "Policy: refunds need a receipt. Customer has none." "Refund allowed?" \
    "allowed=refund is permitted" "denied=refund is not permitted"

# -q prints just the winner, for scripts
$ team=$(decide ask -q "$(cat ticket.txt)" "Which team?" billing shipping tech)

# read the context from stdin
$ cat email.txt | decide ask - "Does it ask for a refund?" yes no

# thousands of decisions from a JSONL file
$ decide score decisions.jsonl
Fast

~0.08 s per decision. The model stays loaded in a small background server that starts on its own.

Private

Runs on your GPU with Apple's MLX. The server only listens on 127.0.0.1.

Jev-compatible

Apps can POST Jev-style requests to localhost:8792/v1/systemone.

How good is it?

On the 231 public JevBench tasks:

AllShort tasksHard tasksMedian time
decide (4B, on an M5 Max)186/231119/12067/1110.08 s
Jev 1.13 (hosted API)198/231119/12079/1110.62 s
Open-Jev 27B (same Mac)198/231117/12081/1111.36 s

It matches much bigger models on short, well-specified decisions: routing, policy checks, intent, extraction, tool choice. It's weaker on long documents and multi-step reasoning, so use a bigger model for those.

  • Probabilities aren't calibrated. Trust the choice; check the confidence on your own labelled examples before relying on it.
  • Wording matters. Give options clear names or descriptions, and keep their order consistent.
  • Inputs are capped at 4,096 tokens (about 3,000 words). Longer ones are rejected, never truncated.

Managing it

$ decide status     # is the background server running?
$ decide stop       # free its memory
$ decide --help

Uninstall with decide stop && uv tool uninstall decide-cli, then delete ~/.decide and the model at ~/.cache/huggingface/hub/models--Qwen--Qwen3.5-4B.

What the installer does

It checks you're on Apple Silicon with Git available, installs uv if needed, installs decide into its own Python 3.12 environment, downloads the pinned model once, and runs a test decision. Read the script before running it.
